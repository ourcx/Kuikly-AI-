# KuiklyStock 需求基线与验收映射

需求来源：[Kuikly AI 股票客户端 Demo 需求文档](https://bytedance.larkoffice.com/docx/Scprdx6IaoeOsgxBO3JcQgPsnGM)，读取版本 `revision_id=5`。

本文用于把需求映射到当前代码与验收证据；飞书文档仍是产品需求基线。

## 必做范围

| 需求 | 当前实现 | 验收入口 |
| --- | --- | --- |
| Android 可安装、启动 | `androidApp` Debug APK | README 构建与安装命令 |
| 行情列表与详情 | 搜索、筛选、排序、列表、统一详情 | 行情 Tab |
| AI 分析与聊天 | 在线 OpenAI 兼容服务 + 离线 Fixture | 研究 Tab |
| 完整会话记录 | 用户/AI 消息、发送中、失败、重试、清空 | 研究会话 |
| Markdown 渲染 | KuiklyMarkdown | AI 回复正文 |
| 股票卡片与走势图 | 可点击股票卡片、Kuikly Canvas 折线 | AI 组合结果 |
| 聊天到详情闭环 | 复用统一详情页，返回研究会话 | 点击 AI 股票卡片 |
| 加载、空态、失败、重试 | 首次加载、无匹配搜索、失败态入口、重新加载 | 行情页 |
| 离线稳定演示 | Remote 失败自动回退 Fixture | 关闭网络后冷启动 |

## 数据与合规边界

- 实时行情优先使用腾讯行情接口，失败后切换 Fixture；UI 显示“腾讯实时行情”或“离线演示数据”。
- AI 优先使用 OpenAI Chat Completions 兼容服务，未配置或失败时回退离线演示回答。
- Token 不硬编码、不写入日志、不提交仓库；错误详情会限制长度并脱敏。
- 详情页和 AI 内容均展示“不构成投资建议”的提示。
- 不提供交易、下单、资金账户或收益承诺。

## 状态验收

1. 冷启动观察行情加载状态。
2. 搜索不存在的代码，观察空态并点击“清除筛选”。
3. 点击行情标题右侧“失败态”，观察错误信息并点击“重新加载”。
4. 在研究页输入“失败”，观察失败消息与原位重试。
5. 不配置在线 AI，发送普通股票问题，确认离线结果仍包含 Markdown、股票卡片和走势图。

## 完成定义

- 新环境按 README 可构建、安装和启动。
- Fixture 模式不依赖网络或临时修改代码。
- 两条主链路可从头到尾操作。
- 文档命令与 Gradle 模块、applicationId、Activity 一致。
- `docs/demo/kuiklystock-demo.mp4` 覆盖交付要求中的关键路径。
- Git 跟踪内容不包含真实密钥、Token、个人凭证和本地构建产物。
