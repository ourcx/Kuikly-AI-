# UI Contracts

## Market entry

Input: none. Output: list state. Actions: select stock, retry, switch demo state, open AI tab.

## Detail entry

Input: valid stock symbol. Output: quote and insight or missing state. Actions: back.

## AI entry

Input: user draft. Output: ordered conversation blocks. Actions: update draft, send, retry, select stock card, switch market tab.

## Accessibility and safety

Positive and negative movement use both sign and color. All AI analysis includes “内容仅供演示，不构成投资建议”。Unknown links and image protocols are not opened.
