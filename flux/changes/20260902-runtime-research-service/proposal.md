# 研究服务运行时接入与界面收敛

## 问题

当前在线研究服务只能在构建 APK 时通过环境变量写入代理地址。普通安装包无法在安装后完成连接，因此在线链路虽然存在，实际交付版本通常只能使用本地分析。同时，页面仍有较多“AI”“WORKBUDDY”“智能终端”等标签化表达。

## 改动

- 增加应用内“服务连接”配置，仅保存 HTTPS 代理 URL，不采集或保存任何凭证。
- 原生层结构化校验 URL，拒绝非 HTTPS、无主机、userinfo 与反斜杠形式。
- 远端 Repository 在每次请求前动态读取配置，保存后无需重启或重建 APK。
- 保留构建时 `WORKBUDDY_PROXY_URL` 作为默认值，运行时配置优先。
- 在线失败继续自动回退本地行情分析，并保持最终回调唯一。
- 将“AI 投研”收敛为“研究”，移除英文眉题、全局在线徽标和过度强调的 AI 文案。

## 验收

- 未配置时本地研究正常可用。
- 在应用内保存合法 HTTPS 地址后，下一次问题走在线代理。
- 非法地址有明确错误且不会保存。
- 移除地址后恢复本地模式。
- 不向客户端增加 Token、Cookie、密码或私钥。
