# 股票客户端功能与 AI 可用性增强规格

## 功能要求

1. 行情页提供名称/代码搜索，输入变化后立即过滤本地行情。
2. 分类 Chip 支持全部、港股、A 股、美股，选中态必须清晰且能实际过滤。
3. 支持默认顺序、涨幅优先、跌幅优先三种排序，并显示当前结果数量。
4. 每个股票卡片支持加入/移出自选；支持“仅看自选”，自选状态在当前应用会话内保持。
5. 每个股票卡片提供“一键问 AI”，自动切换 AI Tab、填入对应问题并发送。
6. AI 使用双通道：配置 WorkBuddy 代理时优先真实请求；未配置或请求失败时自动使用本地行情分析。
7. AI 页面必须明确展示当前来源为 WorkBuddy 或本地分析；本地结果不得伪装成在线服务。
8. AI 支持清空会话；清空后重置消息、草稿、错误和 conversation_id。
9. 市场筛选无结果、自选为空、搜索无结果时显示带恢复入口的空态。
10. 所有业务页面继续使用 Kuikly UI DSL 和 `DesignTokens`，不得引入 Compose 或 Android View 业务 UI。
11. 页面内容统一采用 16px 左右边距、12px 卡片间距；卡片右侧价格列、按钮与标题基线保持一致。
12. WorkBuddy 安全边界保持不变：客户端不持有 Token、Cookie、OAuth 票据或 client secret。

## 边界与错误处理

- 搜索自动去除首尾空格，并忽略大小写匹配 symbol/name/exchange。
- 筛选、排序、搜索和仅看自选可组合使用。
- WorkBuddy 失败后只回调一次最终本地结果；若本地分析也失败，则保留可重试失败消息。
- 本地分析必须包含股票价格、涨跌、观察信息与非投资建议说明。
- 快速 AI 找不到标的时不切换页面。
- 发送中继续阻止重复发送。

## 验收标准

- 默认无 `WORKBUDDY_PROXY_URL` 的 APK 中，AI 提问可正常返回本地分析。
- 配置合法代理后请求优先走 WorkBuddy；代理失败时返回本地分析并显示本地来源。
- 搜索、市场筛选、排序、自选和仅看自选都有可观察状态变化。
- 从任一行情卡片点击“一键问 AI”可直接看到该股票的分析回答。
- 清空会话后消息与 conversation_id 均为空。
- 行情卡片的名称、代码、价格、涨跌、自选和 AI 操作在同一栅格内对齐。
- 新增及现有单元测试全部通过，Android Debug APK 构建成功。
- GitHub `main` 包含最终提交。
