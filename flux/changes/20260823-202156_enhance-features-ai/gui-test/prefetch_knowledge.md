### 当前 Feature 文档预提取知识（时间：2026-08-23）

- 默认入口为行情页；底部导航包含行情与 AI Tab。
- 行情工具区包含搜索框、市场 Chip、排序与仅看自选控制，所有条件可组合。
- 股票卡片包含身份区、固定宽度价格区和底部操作行，可加入自选或一键问 AI。
- AI 页面展示回答来源、输入发送、失败重试与清空会话能力。
- 本地分析必须包含价格、涨跌、观察信息与非投资建议说明。
- 页面统一使用 Kuikly UI DSL 与 DesignTokens，并遵循约 16px 横向边距、12px 卡片间距和一致基线。
